# 武侠·夜 Wuxia Night

夜行衣黑为底、月白为字、剑光冷青为印的深色主题，浅色版为 wuxia。壁纸选用已进入公有领域的中国古代侠义、人物与行旅画，截取局部铺满全屏，部分适度压暗。

![preview](preview.png)

## 安装

```bash
omarchy theme install https://github.com/rwanglq-ctrl/omarchy-wuxia-night-theme
```

## 壁纸来源

1. 商喜《关羽擒将图》轴局部，明（公有领域，图像来自 Wikimedia Commons）
2. 仇英（传）《蜀道春行图》局部，明（公有领域，图像来自 Wikimedia Commons）
3. 陈洪绶《品茶图》局部，明（公有领域，图像来自 Wikimedia Commons）
4. 龚开《中山出游图》局部，宋末元初，弗利尔美术馆（公有领域，图像来自 Wikimedia Commons）
5. 马远《寒江独钓图》局部，南宋，东京国立博物馆（公有领域，图像来自 Wikimedia Commons），适度压暗
6. 范宽《溪山行旅图》轴局部，北宋，台北故宫博物院（公有领域，图像来自 Wikimedia Commons）
7. 关仝《关山行旅图》轴局部，五代，台北故宫博物院（公有领域，图像来自 Wikimedia Commons）
8. 佚名《三骑射雁图》局部，宋，[克利夫兰艺术博物馆](https://clevelandart.org/art/1915.703)（CC0，图像来自该馆开放获取库），适度压暗
