# 武侠·夜 Wuxia Night

夜行衣黑为底、月白为字、剑光冷青为印的深色主题，浅色版为 wuxia。壁纸选用已进入公有领域的中国古代侠义、人物画，截取局部铺满全屏，部分适度压暗。

![preview](preview.png)

## 安装

```bash
omarchy theme install https://github.com/rwanglq-ctrl/omarchy-wuxia-night-theme
```
